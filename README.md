# PC-LI

המחשב שמתאים לי. אפליקציה חינמית לגמרי: בלי פרסומות, בלי עמלות מחנויות.

- בוחרים בשביל מה המחשב וכמה להשקיע, ומקבלים הרכבה שבדוק שהכל בה מתאים.
- מחירים מכמה חנויות בישראל, מתעדכנים כל בוקר מדפי המוצר.
- הסבר בעברית פשוטה לכל חלק, ומדריך הרכבה.

המחירים נמצאים ב-`data/offers.json`. המחיר הקובע הוא תמיד המחיר באתר החנות.
